# For Alisha ♡ — A Moonlit Sanctuary Website

A dedicated gift website featuring:
- **Interactive Wax-Sealed Envelope**: Letter opening ceremony with reveal animations
- **Hero Sanctuary**: High-resolution animated Muslim portrait in starlight and pink roses
- **Urdu Shayari Carousel**: Handpicked couplets in Amiri calligraphy with translation and 1-click clipboard copy
- **Islamic Reminders**: Quranic verses with Arabic calligraphy and reflective English translations
- **Polaroid Photo Gallery**: Interactive photo cards with instant fullscreen Lightbox viewer
- **Interactive Ameen Counter**: Whispers prayers with rising floating heart and crescent particles
- **Canvas Rose Petal Physics**: Gentle ambient falling rose petals across the screen

---

## 🚀 How to deploy to GitHub Pages

1. Create a new repository on [GitHub](https://github.com) (e.g. `for-alisha`).
2. Upload all the files from this folder (`index.html`, `style.css`, `script.js`, and the `assets/` directory) into the repository root.
3. Go to **Settings** > **Pages** in your repository.
4. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
5. Your website will be live at:
   `https://<your-username>.github.io/<repo-name>/`
